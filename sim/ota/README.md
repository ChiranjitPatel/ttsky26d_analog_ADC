## Design

Two-stage Miller OTA, biased from `bias_gen` (`pbias`):

| Device | Type | W/L (µm) | Current | Role |
|---|---|---|---|---|
| M5 | pfet_01v8_lvt | 2/2 × 2 | 2 µA | tail |
| M1, M2 | pfet_01v8_lvt | 8/2 | 1 µA each | input pair (M1 = `inn`, M2 = `inp`) |
| M3, M4 | nfet_01v8 | 1/4 | 1 µA each | mirror load |
| M6 | nfet_01v8 | 1/4 × 4 | 4 µA | 2nd stage (4× M3 density → zero systematic offset) |
| M7 | pfet_01v8_lvt | 2/2 × 4 | 4 µA | 2nd-stage load |
| CC | cap_mim_m3_1 | 18.7 × 18.7 | — | 0.7 pF Miller cap (bottom plate on `out`); was 0.5 pF, raised in stage 3 for the bandgap loop margin |
| RZ | res_xhigh_po_0p35 | L = 7 | — | ≈ 40 kΩ zero-nulling resistor |

- **PMOS input pair:** the bandgap inputs sit at Vbe ≈ 0.55–0.80 V. An NMOS pair (Vgs ≈ 0.6 V)
  would leave the tail current source almost no headroom.
- **Two stages:** a 5-transistor OTA reaches only about 38 dB with these devices. ≥ 50 dB keeps the
  bandgap error from finite gain small (it's multiplied by about 11.5 onto VBG).
- **Output ≈ 0.7 V:** suits driving the gates of `pfet_01v8` current sources in the bandgap core.
- **Power-down:** `pd` = 1 pulls `out` to VDPWR (bandgap PMOS sources off) and `out1` to VGND.

## Phase 1 results (tt, 27 °C, 1.8 V)

See `results.md` (generated): 80.4 dB, 3.0 MHz unity-gain frequency, 81° phase margin with
0.5 pF load (CC = 0.7 pF since stage 3; it was 4.1 MHz / 72° with CC = 0.5 pF), input range ≤ 0.20–1.28 V, 5.8 µA, 0.7 nA powered down.

## Notes for stage 3 and Phase 2

1. **The 0.5 pF load is an estimate.** Re-check stability inside the bandgap loop (stage 3). The
   core's feedback network changes the loop gain and adds poles, so the loop margin, not this
   open-loop margin, is what counts.
2. **Offset σ ≤ 2 mV is still to be checked** with Monte Carlo (Phase 2). Pelgrom estimate for the
   8/2 input pair is ≈ 1–1.5 mV; the 1/4 NMOS loads add to it.
3. **Area:** CC is the largest device (≈ 350 µm² at 0.7 pF). If area gets tight, reduce CC together with the
   bandgap's real load after stage 3.
4. **ngspice-36 quirk:** running `op` after a `tran` with an `alter`ed source gave a false solution
   (v(out) = 2.26 V). Power-down is therefore checked in its own testbench.

## Resize for matching (2026-11-08, from the bandgap Phase 2 Monte Carlo)

Input pair 8/2 → 32/8, loads 1/4 → 4/16 (M6 4 × 4/16), CC 0.7 → 2.1 pF, RZ 40 → 120 kΩ, power-down
devices no longer minimum length, plus 4 layout dummies. The reasons are in `sim/bandgap/README.md`.
- **Offset:** σ = 1.49 mV (target ≤ 2 mV ✅), measured in the bandgap loop as σ(vb − va) over 100 Monte Carlo seeds.
- **Stability:** what counts is the bandgap loop: PM 76.4° at 0.79 MHz (stage 3), and 69.9° with the PTAT branch.
  The stand-alone unity-gain follower with 0.5 pF in `results.md` (PM 21.4°) is not a use case of this cell any more.
  It is the worst-case feedback factor, while in the bandgap the OTA drives about 3 pF at a feedback factor below 1.
  Don't use this OTA as a unity-gain buffer.
