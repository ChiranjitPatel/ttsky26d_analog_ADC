# Stage 5 — VREF chain (vref_filt, vref_buf, vref_sel)

Schematics: `xschem/vref_filt.sch`, `vref_buf.sch`, `vref_sel.sch` (generated by `xschem/gen_vref_*.py`).
Drawing: `material/schematics/stage5_vref.png`. Run: `./run.sh`.

## Design

- **vref_filt:** RF ≈ 1.04 MΩ (9 × xhigh_po 0.35/20) and CF ≈ 3.9 pF (nfet gate cap 10/10 × 5).
  The pole is ≈ 40 kHz. Added on 2026-11-07 for B7 (PSRR at 1 MHz). It adds no DC error because the
  buffer input is a gate.
- **vref_buf:** single-stage follower. NMOS input pair 4/1 (the input is at 1.215 V), pfet_lvt 4/1
  mirror load (diode node ≈ 1.2 V, so offset ≈ −1 mV), 10 µA tail from `nbias`, and CRES ≈ 5.4 pF
  (nfet gate cap 10/10 × 7) on `vref`. CRES is both the charge reservoir for the DAC and the
  dominant pole. A two-stage Miller OTA can't drive that much capacitance stably at useful speed.
- **vref_sel:** `en_buf = NOT(ref_sel OR bg_pd)`, `en_pad = ref_sel OR vref_oe`. A transmission gate
  (nfet 10/0.15 + pfet_lvt 20/0.35) connects `vref` to the `ua[1]` pad when `en_pad` = 1.

## Phase 1 results (tt, 27 °C, 1.8 V)

See `results.md`. B7 is met at `vbg_f` (45.8 dB DC, 20.9 dB at 1 MHz). A 1.2 pF DAC-like load
connected every 1 µs pulls `vref` down by 220 mV (charge sharing), and it recovers to within 25 µV by
the end of each bit cycle (target 2.4 mV). It's stable with and without the pad, and starts in
23 µs (set by the filter). The external-reference and power-down modes work.

## Notes

1. **DMM readout (VREF_OE = 1):** the buffer's closed-loop output resistance is ≈ 1/gm ≈ 12.5 kΩ,
   so a 1 MΩ probe reads ≈ 17 mV low. With a standard 10 MΩ DMM the error is ≈ 1.5 mV.
   The ADC itself draws no DC current from `vref`, so this doesn't affect conversions.
   Put this in the test procedure (`docs/info.md`): measure with ≥ 10 MΩ.
2. **PSRR at `vref`** (33.6 dB DC, 19.9 dB at 1 MHz) is lower than at `vbg_f` at DC, because of the
   single-stage follower. Revisit if the full-ADC tests (I3) show supply-related errors.
3. **External reference:** decouple `ua[1]` off-chip (≥ 100 nF next to the pin). The on-chip CRES
   is then charged through the TG + 500 Ω pad path (τ ≈ 15 ns).
4. **Dead time in DAC switching:** the first load test had both switches on for < 1 ns at each
   transition, which shorted `vref` through 400 Ω and dropped it by 0.55 V. The real DAC switch
   drivers (stage 8) must be break-before-make.
5. **Area:** CF + CRES ≈ 1200 µm² of gate cap, the largest part of the VREF chain.
