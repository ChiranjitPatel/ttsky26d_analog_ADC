# Stage 4 — ptat_out (temperature-sensor voltage)

Schematic: `xschem/ptat_out.sch` (generated by `xschem/gen_ptat_out.py`).
Drawing: `material/schematics/stage4_ptat_out.png`. Run: `./run.sh`.

## Design

MPP (pfet_01v8 8/4, gate on the bandgap's `vgp`) copies the core branch current I = ΔVbe/R1 into
R3 = 22 units of the same res_xhigh_po 0.35/2 used for R1 (2 units). VPTAT = ΔVbe · 22/2, so the
resistor TC cancels and VPTAT is proportional to absolute temperature.

## Phase 1 results (tt, 27 °C, 1.8 V)

See `results.md`: VPTAT = 0.599 V (B10). Adding the branch, or loading `vptat` with 100 kΩ, changes
VBG by nanovolts. The bandgap loop phase margin with the extra gate on `vgp` is 79.9° (82.5° without it).
Early tt-only temperature checks: 2.00 mV/°C (B11), 2.37 °C/LSB (B12).

## Notes for Phase 2 and later stages

1. **B13 (accuracy) here is a tt-only ideal-PTAT estimate (0.5 °C).** Real accuracy also depends on
   MPP/MPA mismatch, R3/R1 mismatch, the OTA offset (ΔVbe error) and the ADC (offset, VREF TC).
   Check it with Monte Carlo in Phase 2.
2. **Source impedance ≈ 266 kΩ.** Like VBG, VPTAT can't be sampled onto the 2.4 pF DAC within a
   1 µs sample phase (τ ≈ 0.64 µs). See the stage 3 README, note 6: decide in stage 7.
