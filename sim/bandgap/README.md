# Stage 3 — bandgap_core

Schematic: `xschem/bandgap_core.sch` (generated by `xschem/gen_bandgap_core.py`; sizes and reasoning there).
Drawing: `material/schematics/stage3_bandgap_core.png`.
Run: `./run.sh` (netlists bias_gen/ota/bandgap_core, makes the loop-break copy, runs the three
testbenches in parallel, writes `results.md` and `plots/bandgap.png`).

## Design

- Three equal pfet_01v8 8/4 current sources (gates on `vgp`, the OTA output) feed:
  A: Q1 (1×), B: R1 + Q2 (8×), C: R2 + Q3 (1×) → `vbg`.
- The OTA (stage 2) forces va = vb, so I = ΔVbe / R1 ≈ 2.26 µA per branch and
  VBG = Vbe + (R2/R1)·ΔVbe.
- R1 = 2 and R2 = 19 identical res_xhigh_po 0.35/2 units (≈ 12.1 kΩ each), so R2/R1 = 9.5 exactly by unit count.
- Startup: MSU2 (1 µA from `pbias`) pulls `su` high while `vbg` is low; MSU1 then pulls `vgp`
  low. Once `vbg` is up, MSU3 holds `su` at ≈ 7 mV.
- `vgp` is a port so the PTAT branch (stage 4) can mirror the core current.

## Phase 1 results (tt, 27 °C, 1.8 V)

See `results.md`. B1, B2, B3 pass; the loop is stable with 82.5° phase margin; startup works on a
1 µs and a 100 µs supply ramp.

## Findings and decisions

1. **R2/R1 tuned to 9.5, not stage 0's 10.54.** The branch current I = ΔVbe/R1 rises strongly
   with temperature because xhigh_po has TC1 ≈ −1470 ppm/K. That flattens Vbe(T), so less PTAT gain
   is needed. Sweep at tt: 19/2 → 22 ppm/°C (peak near 30 °C); 20/2 → 64 ppm/°C; 21/2 → 132 ppm/°C.
2. **The zero-TC VBG of this circuit is ≈ 1.215 V,** inside B1 (1.21–1.29 V) but only 5 mV above
   the minimum. Corners will push it outside. **Proposal (needs sign-off):** set B1 to
   1.215 V typ, 1.18–1.25 V (±3 %, same as B6). The ADC LSB becomes 4.75 mV.
3. **OTA Miller cap raised from 0.5 pF to 0.7 pF** (stage 2 re-run: still 80 dB, 81° PM at 0.5 pF).
   The 56° measured with 0.5 pF turned out to include a stray 2.4 pF cap (see note 8), so the raise may
   not be needed. Without that cap the loop has 82.5° at 0.7 pF. **Area option (Phase 2):** go back to
   0.5 pF (saves ≈ 100 µm²) if corners keep ≥ 60°.
4. **Loop-gain method:** an L/C break at the OTA output gives wrong results here, because all the
   gate load ends up on the source-driven side. `tb_bandgap_loop` uses Middlebrook double injection
   (voltage + current), which is exact for any loading.
5. **PSRR at 1 MHz fails (−9.8 dB; B7 needs ≥ 20 dB).** At 1 MHz the loop gain is only ~2, and the
   OTA output (≈ 1/gm6 ≈ 30 kΩ to ground) can't keep `vgp` tracking VDPWR. Supply ripple therefore
   modulates the PMOS currents and appears on `vbg` × (R2 + re). A 1–2 pF cap from `vgp` to VDPWR
   barely helps (tried, removed). **Proposal:** an RC low-pass between `vbg` and the VREF buffer
   input (stage 5), e.g. ≈ 1 MΩ xhigh_po + ≈ 4 pF MOS cap (pole ≈ 40 kHz, ≈ 28 dB at 1 MHz). It
   also filters bandgap noise. It's free of DC error because the buffer input is a gate.
6. **Sampling high-impedance nodes (for stages 4/7/I4):** `vbg` has ≈ 240 kΩ source impedance.
   Sampling it (or VPTAT) directly onto the 2.4 pF DAC through `INSEL` gives τ ≈ 0.6 µs, so it doesn't
   settle in a 1 µs sample phase. INSEL = VBG/VPTAT needs a longer sample phase (≥ 10 τ ≈ 6 µs, e.g.
   a slower clock or a sample-extend mode) or a buffer. To be decided in stage 7.
7. **Headroom:** VBG starts dropping below VDPWR ≈ 1.6 V at tt (see the line plot). Check at
   ss/−40 °C in Phase 2. The current-mode bandgap fallback stays open.
8. **Correction (2026-11-07): stale schematic.** The PSRR-cap sweep in this stage overwrote
   `xschem/bandgap_core.sch` with CPS_W = 14 (a 2.4 pF MOS cap from `vgp` to VDPWR). The generator
   was reset to CPS_W = 0, but the schematic wasn't regenerated, so the committed schematic and every
   result in stages 3, 4, 5 and 7 included that cap. All four stages were rerun without it. Everything
   still passes; phase margin 65.7° → 82.5°, PSRR at 1 MHz −9.8 → −8.9 dB (raw `vbg`).
   `tools/netlist.sh` now regenerates every schematic from its generator before netlisting.

## Phase 2 — mismatch (Monte Carlo), 2026-11-08

`tb_bandgap_mc.spice`: `.op` + a −40…125 °C sweep per seed, run with
`../../tools/run_corners.py tb_bandgap_mc.spice --mc 100 --mc-corner tt_mm`, statistics with
`python3 mc_stats.py tb_bandgap_mc`. (The runner now puts the seed into `.spiceinit`, because the mismatch
parameters are drawn while the netlist is parsed. A seed set in `.control` had no effect.)

**First result: σ(VBG) = 54 mV** (range 1.090–1.350 V, 98 of 100 seeds converged). That alone is
larger than the whole ±3 % (±36 mV) of B6. VBG correlates 0.94 with the loop's input error `vb − va`
(σ 4.6 mV). That error is amplified by 1 + R2/R1 ≈ 10.5.

Sizing experiments (40 seeds each; netlist variants made by text substitution, so the old baseline isn't kept):

| Variant | σ(VBG) | σ(vb − va) | Conclusion |
|---|---|---|---|
| baseline (pair 8/2, loads 1/4, sources 8/4, R 0.35/2) | 54.1 mV | 4.61 mV | |
| A: OTA loads 4/16 | 45.5 | 4.47 | loads matter a little |
| B: OTA input pair 16/4 | 34.8 | 2.97 | the input pair matters most |
| C: A + B | 25.5 | 2.13 | |
| D: C + sources 16/8 | 27.7 | 2.36 | no gain while the OTA dominates |
| F: C with input pair 32/8 | 19.3 | 1.21 | |
| G: ideal OTA (gain 10⁴, no offset) | 18.2 | 0 | everything that isn't the OTA |
| H: G + R units 0.69/4 | 12.2 | 0 | the resistor ratio is ≈ 15 mV at 0.35/2 |
| I: G + ideal resistors | 10.5 | 0 | PNPs + sources |
| J: I + sources 16/8 | 6.5 | 0 | sources ≈ 8 mV at 8/4, PNPs ≈ 5 mV |
| K: final, with loads 2/32 (strong inversion) | 14.2 | 1.10 | **rejected:** 1 seed in 100 broke the loop |

**Adopted:** input pair 32/8, loads 4/16 (M6 4 × 4/16), sources 16/8 (also `ptat_out`'s MPP), R units 0.69/4
(also R3). **Result (100 seeds): σ(VBG) = 17.6 mV** (1.170–1.248 V), σ(vb − va) = 1.49 mV, σ of
VBG(125 °C) − VBG(−40 °C) = 5.4 mV, all seeds converged. This is 3× better, but the 3σ of ±53 mV is still above B6's ±3 %.
The OTA offset is still the largest part (≈ 9.5 × 1.5 mV). What remains for the spec decision is in `docs/specs/bandgap.md` (B6 note).

What the resize broke and how it was fixed:
1. **Loop phase margin 82.5° → 9.5°.** The larger gates put about 3 pF on `vgp` and lowered the mirror pole.
   CC went from 0.7 to 2.1 pF (32 × 32 µm MIM, which can sit over the OTA devices) and RZ from 40 to 120 kΩ:
   PM 76.4°, crossover 0.79 MHz. (A 2× second-stage current alone gave at most 56°. A cap from `vgp` to
   VDPWR made PSRR worse.)
2. **Startup limit cycle.** After a 1 µs ramp, VBG swung between 0.7 and 1.7 V for the whole 40 µs. The
   startup pull-down MSU1 (0.42/1) slammed `vgp` low every time VBG dipped below MSU3's threshold. MSU1 is now
   0.42/4: VBG settles in 2.4 µs, and the 100 µs ramp still starts.
3. **B7 at 1 MHz fell to 16 dB**, because the slower loop doesn't regulate there. The RC filter grew: 14 units
   (1.6 MΩ) and 7 caps (5.5 pF) give 22.2 dB. VREF now settles in 43 µs after power-up (the target is now
   100 µs, power-up only).

Phase 1 after the resize (tt, 27 °C, 1.8 V): VBG 1.2105 V, TC 23.5 ppm/°C, line 2.2 mV/V,
15.7 µA, PM 76.4°, startup 2.4 µs. VPTAT 0.6005 V, 1.956 mV/°C (`sim/ptat`).
